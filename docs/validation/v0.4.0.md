# Android validation - 0.4.0

The signed versionCode 6 APK was installed as an update on this machine's API 35 emulator with WebView 124.0.6367.219. Production export, Android release build and 202 automated tests in 21 files passed. Signing matches the previous release. A scan of APK entries found none of the three configured secret values checked; metadata credentials remain server-side.

| Final measured check | Result |
| --- | --- |
| Launch to Discover, including ADB/DevTools overhead | 3.06 s |
| Launch to online catalog rows | 5.33 s |
| Library / Guides / Settings DOM readiness | 0.30 / 0.37 / 0.29 s |
| Three sequential gateway requests, each 20 entries | 77 / 83 / 77 ms |
| Cancel to temporary-file cleanup | 249 ms |
| Retry to saved generated 4,447,813-byte CBZ | 2.73 s |
| Stalled source to visible failure, including navigation | 12.56 s |
| Three-page local import / offline image readiness | 0.77 / 0.77 s |

All 14 download checks passed: a real partial file existed before cancellation, progress survived client navigation, cancellation removed temporary bytes, retry imported readable pages, oversized declared and streamed bodies failed, verification HTML failed, broken/stalled connections failed, source authorization was sent only to the intended origin, redirects dropped authorization, and process death became an interrupted job with clean temporary storage and successful retry. Retry sent no Range header. Personal backup contained 208 series, 12 library records and no accounts; restore passed through the UI.

Page 2 survived backgrounding, rotation and process restart. A gateway request with 300 ms simulated latency and 64 KB/s throughput returned 20 entries in 1.79 s.

Screenshots were reviewed for progress, the downloaded generated page, source errors and interrupted recovery. Earlier history is collapsed so it does not bury the library. The fixture is generated noise with a page label, not a failed comic image. Main-screen and reading screenshots are included with raw reports in the release validation ZIP.

Exploratory failures are retained locally: a selector expected an older card now hidden by collapsed history; a form submission happened before readiness; and a slow emulator run took 17.37 s to retry and exceeded the harness's former 40 s oversized-stream wait. The harness now allows 150 s to observe the native 120 s deadline, waits for loaded feed controls and updates inputs separately. The final full download rerun passed. An earlier product issue that mixed native transfer IDs into job IDs was fixed and covered by an automated regression test.

These are individual samples, not speed guarantees. Loopback download timings do not represent remote comic hosts. Protected source reading was unchanged and not revalidated in this pass. Physical phones, current WebView, larger/solid archives, OS background downloading, range resume, provider review and gateway quotas remain outstanding.
