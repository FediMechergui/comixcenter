# Android validation - 0.3.0

Signed APK installed as an update on the API 35 test emulator, using Android System WebView 124.0.6367.219. A current WebView and physical phone still need coverage. 186 automated web/engine tests passed; production export and Android release build passed. No physical-phone acceptance is claimed.

| Launch to online catalog rows | 5.79 s |

| Gateway with 300 ms latency and 64 KB/s throughput | 1.76 s, 20 entries |

Source page 3 was saved, returned to ComixCenter history and restored after reopening. Imported page 2 survived backgrounding, rotation and process restart. Personal backup was written through the native filesystem/share flow and restored through the preview/confirmation UI. It contained 208 series and no account settings. Screenshots were visually reviewed, including actual offline and resumed source pages.

Source latency remains variable: another successful run reached the first image in 4.53 s. Emulator startup also varied substantially in exploratory runs. These are individual samples, not a benchmark distribution or a guaranteed speedup. Slow protected sources and larger-device coverage remain 1.0 gates.
