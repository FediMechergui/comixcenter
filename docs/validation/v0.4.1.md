# Android validation - 0.4.1

Signed versionCode 7 was installed as an update on the API 35 emulator with WebView 124.0.6367.219. Production export, Android release build and 207 automated tests in 22 files passed. Signing matches the previous release. Three configured secret values were checked against APK entries with zero matches.

All eight source-catalog checks passed: a live catalog persisted, matching listings remained visible with Wi-Fi and data disabled, and Characters, Events and Community guides opened at their requested native source URLs without exposing Capacitor's native bridge. Actual headings were present for all three sections. These timings measure document/heading readiness, not every image, stylesheet or interactive control being ready. The character screenshot includes the source site's welcome overlay; events and guides show source content still loading assets. Offline listings do not imply offline source pages or covers.

Main screens, offline listings and all three source screenshots were reviewed. The offline screenshot was recaptured after scrolling to the actual catalog. The first exploratory source test captured an empty initial document and attempted its next action before the asynchronous Close completed; the harness now waits for headings/verification and the enabled launch button before continuing. Android's UI dump emitted transient null-root diagnostics in the successful run; Close returned correctly and all checks completed.

Both main runs were significantly slower than the preceding 0.4.0 run. No speed improvement is claimed, and host/emulator/network contributions have not been isolated. Keep the raw measurements when comparing later builds. No download or local-reader behavior changed; the full 0.4.0 download/reading/lifecycle results are prior evidence, not suites rerun for this patch.

A plain HTTP request to Batcave from this machine returned 403. The working alternative in this run was ordinary public-page navigation inside the phone's source browser. No full-site ingestion, verification bypass or unrestricted API is claimed. Provider review, physical-phone/current-WebView testing and the other [1.0 gates](../road-to-1.0.md) remain open. Raw reports and screenshots accompany the release; aggregate results: [v0.4.1.json](v0.4.1.json).
