# ComixCenter 0.2.2 preview

Online comics now offer **Open source reader in app**, without switching to an external browser or requiring a PC. A separate Android WebView displays the source website and any verification it requires, keeping its cookies on the phone. Close returns to the ComixCenter reader; Android Back navigates source history.

The source browser has reload, pinch zoom and persistent source cookies. It has no Capacitor bridge, cannot open local files, and restricts top-level navigation to supported comic source domains.

Vercel remains the discovery and metadata gateway. Protected reading uses the phone's source browser directly; it does not transfer verification cookies to Vercel. A source can still reject Android WebView, so playback is not guaranteed. This adds a source-site reading mode, not custom page extraction or offline downloads.
