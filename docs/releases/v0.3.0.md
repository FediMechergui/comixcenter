# ComixCenter 0.3.0 preview - reading reliability and recovery

- Read opens the source reader directly on Android, with the ComixCenter page reader available as an alternative.
- Source sessions remember URL, page selection and scroll position and appear on the continue shelf. Native progress is sampled while reading and saved on Close/background.
- Discover offers direct Batcave browsing inside the APK, independent of the cloud catalog's source restrictions.
- Personal JSON backup and previewed restore include catalog, custom reading orders, guide checklists and progress. Account secrets, browser cookies and comic bytes are excluded. Reimport identical files to recover their saved progress.
- Four daily navigation tabs: Discover, Library, Reading paths and Search. Catalog browsing remains accessible through Discover and the desktop rail.
- Reading guides show the next unread stop; local search distinguishes series editions by year.
- Library shows offline page counts and original archive sizes. Imports are limited to 64 MB, cannot overlap, and multi-file import can stop after the active file.
- In-app privacy and source information.

## Validation

The Android emulator is used for screenshots, route readiness and gateway latency, plus source page resume, generated CBZ import, offline reading, and backup/restore through the UI. Reusable scripts live in scripts/android-*-smoke.py; outputs are in scratch/android-validation. Automated engine tests cover recovery rollback, credential exclusion, pending-file recovery and edition search.

Latency varies with emulator load, network and source behavior. A cached API response is not the same measurement as a comic image becoming visible. See the validation report for measured runs.

## Before 1.0

This remains a preview. Protected sources can still reject WebView or cloud requests. Broad physical-phone testing, a cancellable download manager for large files, provider permission review and shared-gateway quota controls remain release gates. No source availability guarantee is made.
