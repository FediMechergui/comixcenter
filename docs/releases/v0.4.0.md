# ComixCenter 0.4.0 preview - cancellable downloads and recovery

- Save supported direct comic files from OPDS feeds with byte progress, page-import progress and cancellation. Downloads continue across app screens while the app process stays alive.
- Library shows the latest download, with expandable earlier history, explicit Retry and Read saved comic actions. Interrupted transfers restart from the beginning; no silent retries or byte-range resume.
- Android streams downloads into private temporary files instead of passing base64 archives through the native bridge. Cancelled, failed and abandoned temporary files are cleaned up.
- Connection idle and overall transfer deadlines replace indefinite waiting. Oversized files, broken responses and HTML verification pages produce actionable errors.
- Feed authorization stays on its origin and is removed on cross-origin redirects. HTTPS downloads cannot redirect to HTTP.
- Import cancellation rolls back partial library records and extracted pages. Startup recovers interrupted imports, and backup restore cannot overlap an import.
- Direct downloads remain limited to 64 MB and imports to 2,000 pages. ZIP metadata is checked before extraction, with 32 MB per entry and 256 MB total declared uncompressed limits. Other archive formats still need broader large-file testing.

## Validation

202 automated tests passed, along with production export and signed Android release build. The installed APK was exercised on this machine's API 35 emulator: main screens and gateway latency, 14 download checks, generated comic reading offline, and personal backup/restore. Screenshots and measured results are included in the release validation ZIP and [validation report](../validation/v0.4.0.md).

## Before 1.0

This is a preview. Downloads require the app process to remain alive; no Android background service or byte-range resume is implemented. A physical phone with current Android System WebView, larger archives, provider permission/attribution review and shared gateway quota controls remain release gates. Protected sources may reject cloud requests or embedded browsers; this update does not bypass verification or guarantee source availability. Metadata credentials stay on the server, outside the APK.
