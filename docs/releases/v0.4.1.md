# ComixCenter 0.4.1 preview - Batcave exploration and saved listings

- Discover opens Batcave's public Characters, Events and reading orders, Community guides, or All comics sections inside Android's source browser. The phone retains its own source session; credentials and verification cookies are not relayed to Vercel.
- Successfully loaded online catalog pages are saved on the device. When sources fail, the matching saved source/query/page appears with its timestamp and a retry action. Offline browsing uses saved listings immediately when the WebView reports offline.
- Saved listings expire after seven days and retain at most 12 pages within a 500,000-character storage budget. They contain catalog listings, not downloaded comic pages; covers and source reading still require connectivity.

## Batcave investigation

Batcave publishes [characters](https://batcave.biz/characters/), [events](https://batcave.biz/event/) and [community guides](https://batcave.biz/folder/) on its website. A plain public HTTP request from this machine returned 403, while the public pages were visible through web browsing. Neither proves an unrestricted API exists. This release uses public section navigation in the existing native source view and improves resilience of listings already loaded successfully. It does not ingest the entire site or bypass protection. Source availability is measured separately from app navigation.

## Validation and remaining work

Physical-phone/current-WebView acceptance, larger archive coverage, provider review and gateway quota controls remain 1.0 gates.
