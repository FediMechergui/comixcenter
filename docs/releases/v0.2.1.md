# ComixCenter 0.2.1 preview

- Hosted Vercel source gateway: online discovery works without a running computer.
- Automatic source selection plus explicit Batcave and GetComics options.
- Short request deadlines, actionable errors, retry, and no implicit emulator-server fallback on phones.
- Metadata credentials stay in Vercel environment variables, outside the APK.
- Online chapter pagination and opening the issue selected from a source link.
- Bundled catalog and reading guides remain available offline.

Gateway: https://comixcenter-gateway.vercel.app

Protected sources can reject cloud and native requests. This release does not bypass source verification; Batcave's optional desktop browser connection remains available. GetComics downloads may require source-specific steps.
