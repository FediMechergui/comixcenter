# ComixCenter 0.2.0 — phone testing prerelease

This release connects discovery, preloaded reading guides and an in-app online reader.

## Install

Download `ComixCenter-0.2.0.apk` and install it on your Android phone. This is a signed release build,
not the debug APK. If Android refuses an update because an installed debug build uses another
signing key, export any important local data before uninstalling that debug build.

## What's included

- A simpler Discover screen, universe browsing and reading-path navigation.
- Twelve bundled editorial guides with 66 reading stops, including Marvel/DC mainlines,
  Ultimate, Absolute, Batman, Superman, Krakoa, Invincible, Hellboy and Energon.
- Batcave as the primary online source: releases, series search, chapter lists, cover caching
  and a reader with page/scroll modes, fullscreen, keyboard controls and next-issue navigation.
- Device-local reading history and guide checklists; character milestones with spoiler controls.
- Safer imports, atomic snapshot loading, persistent browser storage and protected library changes.

## Sources and accounts

Batcave is the main discovery source. When its native requests are blocked, start
`start-server.bat` on a computer with Chrome/Edge and set its LAN address in the phone's
Settings > Batcave browser connection. The phone retains its own catalog. The computer handles
protected requests through its dedicated normal browser session and must remain running.
A source may occasionally ask for verification in that browser window.

ReadComicsOnline remains an alternative reader in device mode. GetComics remains available
as the built-in OPDS-shaped feed for supported imports and reader links. Mirror landing pages
are not direct comic files. Automatic cross-source edition comparison and failover are not
implemented in this release; different editions should be selected explicitly.

Metadata comes from the bundled snapshot, GCD, Metron and Comic Vine. Add personal metadata
credentials in Settings, or keep server credentials in `backend/.env`. Account passwords and
API secrets are not embedded in the APK. Guides are editorial starting paths, not exhaustive
catalogs, and phone/server catalogs remain separate.

## Validation and phone test

The prior implementation passed 84 backend tests, 176 frontend tests, TypeScript/static-export
builds, and desktop/mobile-width browser checks. Real Batcave pages rendered in the app and
reading position persisted. The signed release is built and signature-verified before upload.
Physical-phone behavior is awaiting this prerelease test.

Please test:

1. Fresh install, bundled catalog and guides before entering any credentials.
2. Batcave discovery/search, chapter selection and the browser connection from your Wi-Fi.
3. Page/scroll modes, chapter switching, resume after closing the app and Android Back.
4. GetComics feed imports and alternative ReadComicsOnline reader links.
5. Cover/edition correctness, missing chapters, long-issue memory use and offline owned comics.
